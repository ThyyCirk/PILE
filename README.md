## PILE - Personal Intelligent Link Engine

Special gadget that you can use to track your phisical and mental health,
to journal, keep track of time, and more!

[Download Latest Release](https://github.com/ThyyCirk/PILE/releases/latest)

## user file system directory structure

```shell
├── README.md           ----> this file
├── apps                ----> user app scripts
│   └── Pile.py       ----> PILE
├── boot.py             ----> boot file
├── libs                ----> libraries
│   ├── README.md
│   └── __init__.py
├── main.py             ----> main file
└── res                 ----> resource files
    ├── font            ----> font files
    │   
    └── img             ----> image files
        ├── default.jpg
        ├── default.png
        ├── uiflow.bmp
        ├── uiflow.jpg
        └── uiflow.png
        └── ...
```
